Fewer predictors. What changes?

Removing most interactions cuts hundreds of fitted terms. It improves some initial metrics, but removing all face–mask interactions also removes personalized mask ordering.

7 people · 421 held-out observations · train on 6, test on the 7th · same fixed scaling ranges · C = 1 · 50% cutoff

Recommended compact candidate: retain shared face-by-mask-perimeter interactions, while removing category-specific facial interactions. This preserves some mask-size personalization with far fewer coefficients. It is a candidate for further validation, not an established winning model.

Exact terms in each feature set

All four versions are logistic regressions: predicted fit probability = sigmoid(L) = 1 / (1 + exp(−L)). The terms below form the logit L, before that probability transformation.

z₁, …, zd · facial predictors
Traditional: d = 6, in this order: face width, face length, bitragion–subnasale arc, nose protrusion, nasal root breadth and nose bridge height. PCA: d = 3, the first three components of those same six fixed-range-scaled measurements, fitted on training people and rescaled using analytic component bounds. Both versions use facial predictors bounded to [0, 1] for in-range measurements.
p · mask perimeter
The observed mask perimeter, scaled as (perimeter in mm − 100) / 700.
c₁, …, cK · mask-category indicators
One-hot indicators for fit family, style and strap type, concatenated into one vector. For example, a Bifold style contributes a 1 in the Bifold indicator and 0 in the other style indicators. Categories are learned from training data; an unseen category contributes zeros in its block. K = 57–61 indicator columns across the original training folds. These are category main effects, not facial measurements.
B · intercept and category main effects
B = β₀ + Σk=1…K γkck. Every feature set includes this block. β₀ is the intercept; each γ is a fitted category coefficient.

1 · Linear only

L = B + αp + Σj=1…d βjzj

Terms: category indicators, mask perimeter, and each facial measurement or PC. No squares and no products between predictors.

Predictors: K + d + 1, plus one intercept.

2 · Linear + squared, without interactions

L = B + α₁p + α₂p²+ Σj=1…d (βjzj + δjzj²)

Adds each facial measurement/PC squared and mask perimeter squared. A square such as z₁² allows curvature in that predictor’s effect, but it does not couple the face to a mask.

Predictors: K + 2d + 2, plus one intercept.

3 · Shared perimeter interactions

L = [all terms in feature set 2]+ Σj=1…d (ηjzjp + θjzj²p)

Adds two products per facial predictor: its linear term × mask perimeter and its squared term × mask perimeter. For example: scaled face width × scaled mask perimeter, and scaled face width² × scaled mask perimeter.

The interaction coefficients are shared across mask categories. These products allow the effect of mask perimeter to change with facial geometry; no category gets its own facial slope.

Predictors: K + 4d + 2, plus one intercept.

4 · Full interactions · slide 12 baseline

L = [all terms in feature set 3]+ Σk=1…K Σj=1…d (κkjckzj + λkjckzj²)

Adds each category indicator × each linear and squared facial predictor. Examples: Bifold indicator × face width, fit-family indicator × nose protrusion², or Headstrap indicator × PC₁. Each fit family, style and strap category can therefore have its own facial coefficients.

Predictors: K + 4d + 2 + 2dK = (2d + 1)K + 4d + 2, plus one intercept. The 2dK category-by-face terms explain most of the expansion.

Each feature set is fitted independently. “All terms in feature set 2/3” describes included columns, not reuse of previously fitted coefficient values. Coefficient signs are unconstrained; all versions use the existing L2 regularization setting C = 1. None includes face-to-face products zᵢzⱼ for i ≠ j, p² × facial terms, products between category indicators, or a prescribed face-minus-mask deviation feature. Predictor counts are raw design columns, not independent degrees of freedom; the one-hot blocks and intercept contain redundant columns. PCA loadings are preprocessing parameters and are not included in these classifier counts.

Fixed scaling ranges and PCA score bounds

Each physical value x is transformed as (x − minimum) / (maximum − minimum). Out-of-range measurements raise an error; they are not silently clipped. These bounds are provisional engineering assumptions, not validated population limits.

For PCA component loadings v, define a = Σ min(vᵢ, 0) and w = Σ |vᵢ|. Its bounded score is z = (xscaled · v − a) / w. These are analytic extrema over the fixed input unit cube, rather than extrema estimated from held-out people. PCA is fitted without whitening.

ARKit + nose: how many predictors?

Four measured facial paths → two geometric summaries → 215–231 learned parameters across the original seven leave-one-person-out folds.

The four facial measurements are the nose, upper-cheek, mid-cheek and chin paths. Their sum is the total facial perimeter; the nose path is also used separately. The model additionally receives observed mask perimeter and fit-family, style and strap-type categories. The facial strap-path measurement is not used by this logit; strap type is categorical.

Thus “two geometric summaries” does not mean two fitted coefficients. The model learns family/style-specific perimeter coefficients and preferred nose distances.

ΔP = (Pface − Pmask) / 10;   N = nose path in mm / 10L = (af + as)ΔP² + (bf + bs)ΔP + cf + cs + tr− softplus(q)[N − exp(u₀ + uf + us)]²

Here f is fit family, s is style, and r is strap type. The a coefficients are constrained negative via a = −exp(α). Nose mismatch strength softplus(q) is positive and shared across styles in this model; the preferred nose distance exp(u₀ + uf + us) is learned. Lengths enter in centimeters, rather than the fixed [0, 1] ranges used for the traditional/PCA comparisons. Fit probability is sigmoid(L).

Why keep a few interactions?

Without interactions, the logit is f(face) + g(mask). When comparing two masks for the same person, f(face) cancels. Everyone therefore receives the same relative mask ranking within one fitted model, even if squared main effects are included.

Shared face-by-perimeter interactions let the effect of mask size depend on the face. They preserve some personalization without estimating a separate facial relationship for every mask family or style.

Production ARKit: approximately 5.7 false positives, averaged over three initializations. The simpler linear models reduce errors relative to the full fixed-range models, but do not resolve the gap. Child-specific recall cannot be measured because this fold contains no positive labels.

Interpretation boundary: seven people remain seven independent people. These are exploratory comparisons on the same cohort. Selecting a recipe because it looks best here would give an optimistic estimate; previous bootstrap intervals do not apply to these new feature sets.

What to test next

  1. Keep the compact shared-perimeter interaction model as a personalized candidate, and the additive models as comparison cases.
  2. Select regularization inside training-person-only folds, then evaluate the complete selection procedure on held-out people.
  3. Bootstrap the chosen procedure with refitting, and validate on additional independent people, particularly children and larger faces.

Preprocessing and PCA were fitted on training people only. Regularization strength and the decision threshold were fixed in this experiment; no new nested selection or bootstrap was performed. The full-interaction baseline reproduces slide 12’s frozen metrics within 1e−12.
